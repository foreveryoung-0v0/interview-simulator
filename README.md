## 💡 项目背景（解决什么痛点？）
在当前的求职环境下，大学生在找实习时普遍面临“面试焦虑”、“简历注水”和“缺乏复盘经验”的问题。
虽然目前有许多通用 AI 聊天工具，但它们往往**过于温和**，倾向于鼓励用户，无法真实模拟职场中的高压环境。导致很多同学用 AI 模拟时感觉良好，一上真实战场被 HR 连环追问就原形毕露。

本项目旨在打造一款**“反内耗”**的面试工具，拒绝虚假鼓励，用真实的“压力面试”帮大学生提前脱敏。

## ✨ 核心功能
- **🔥 沉浸式压力面**：内置深度定制的 System Prompt，强制 AI 扮演 10 年经验的“毒舌 HRD”，拒绝温和，专挑简历漏洞。
- **🕵️ 简历精准深挖**：拒绝泛泛而谈，AI 会根据你输入的目标岗位和简历内容，进行针对性的连番追问（例如：揪住“10万+爆款”的阅读量真实性不放）。
- **📊 STAR 法则复盘**：输入“结束面试”后，AI 会立刻停止角色扮演，为你提供 0-100 的打分、简历修改建议，并给出刚才回答较差问题的“高情商标准话术”。

## 🛠️ 技术架构与开源声明
本项目遵循 **“轻量化、开源化、可复用”** 的理念进行开发：
- **UI 与底层架构**：基于开源单文件前端项目 `SmartYRC` 进行二次开发。重构了左右分栏布局，提升产品感。
- **大语言模型**：接入 `DeepSeek` API，提供强大的中文逻辑推理与长上下文理解能力。
- **前端排版**：引入开源库 `marked.js`，实现 AI 回复的 Markdown 实时渲染，提升阅读体验。

> **自主开发边界**：本项目的核心壁垒在于深度的 **Prompt Engineering（提示词工程）**。团队重写了系统提示词，将“压力面试规则”、“连环追问逻辑”与“STAR法则复盘指令”硬编码注入 AI，使其具备专属的职场人设，而非简单的模型调用。

## 🚀 如何本地运行（开发者指南）
由于本项目纯前端构建，无需配置后端环境，只需三步即可跑通：
1. 克隆或下载本仓库的 `index.html` 文件。
2. 用文本编辑器打开，找到第 76 行：
   `const API_KEY = '这里填你的Key';`
3. 将引号内的内容替换为你自己在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请的 API Key。保存后，双击用浏览器打开即可使用。
